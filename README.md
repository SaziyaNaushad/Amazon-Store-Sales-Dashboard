# Amazon Store Sales Dashboard – Power BI

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze Amazon store sales performance and identify trends across products, categories, and revenue.

The dashboard provides a clear view of key sales metrics and helps explore business performance through interactive visualizations and filters.

## 🎯 Objective

The objective of this project is to analyze Amazon store sales data and understand:

- Overall sales performance
- Revenue trends
- Product and category performance
- Customer-related insights
- Key business trends

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Microsoft Excel
- Data Visualization

## 🔄 Data Preparation

The dataset was prepared and analyzed before building the dashboard.

Key steps included:

- Data cleaning
- Data type checking
- Handling missing/incorrect values
- Data transformation
- Creating calculated measures using DAX

## 📈 Dashboard Features

The dashboard includes:

- Sales overview
- Revenue analysis
- Product performance
- Category analysis
- Customer insights
- Revenue trends
- Interactive filters and visuals

## 🔍 Key Insights

The dashboard was used to identify:

- Sales performance across different products and categories
- Revenue trends over time
- Top-performing products
- Differences in category-level performance
- Important patterns in store sales data
